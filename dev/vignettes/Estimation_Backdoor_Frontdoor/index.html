Estimation: Backdoor and Front-Door

This vignette covers the common estimate_causal() workflows for backdoor and front-door style graphs.

Backdoor

using CausalGraphs, DataFrames, Random

Random.seed!(1)
n = 500
X = randn(n)
A = Float64.(rand(n) .< 1 ./ (1 .+ exp.(-X)))
Y = 2 .* A .+ X .+ randn(n)
data = DataFrame(X=X, A=A, Y=Y)

graph = make_graph(
    vertices = [:X, :A, :Y],
    di_edges = [(:X, :A), (:X, :Y), (:A, :Y)],
)

identify(graph, :A, :Y).strategy
:a_fixable
draw_graph(graph)
res = estimate_causal(
    a = [1, 0],
    data = data,
    graph = graph,
    treatment = :A,
    outcome = :Y,
)

res[:TMLE].ACE
2.0321394471141216

For an a-fixable treatment, estimate_causal() uses the Markov pillow of the treatment as the adjustment set and returns TMLE, one-step/AIPW, G-computation, and IPW estimates.

Front-Door / P-Fixable

Random.seed!(2)
n = 700
A = Float64.(rand(n) .< 0.5)
M = 0.8 .* A .+ randn(n)
Y = 1.5 .* M .+ randn(n)
fd_data = DataFrame(A=A, M=M, Y=Y)

fd_graph = make_graph(
    vertices = [:A, :M, :Y],
    di_edges = [(:A, :M), (:M, :Y)],
    bi_edges = [(:A, :Y)],
)

identify(fd_graph, :A, :Y).strategy
:p_fixable
draw_graph(fd_graph)
fd_res = estimate_causal(
    a = [1, 0],
    data = fd_data,
    graph = fd_graph,
    treatment = :A,
    outcome = :Y,
)

fd_res[:TMLE].ACE
1.210851508688629

For a p-fixable graph, the package routes to the NPS/front-door style TMLE.
