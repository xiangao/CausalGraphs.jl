Part 1: Nested-Fixable Estimation (ANIPW)

The identification hierarchy

a-fixable  ⊂  p-fixable  ⊂  nested-fixable  ⊂  identified

A treatment is nested-fixable when the effect is identified by the One-Line ID algorithm, but is neither a-fixable nor p-fixable. This occurs when a child of the treatment shares a hidden common cause with the treatment — so neither backdoor nor front-door adjustment is sufficient.

Example: HIV treatment graph

This example comes from the anankeR estimation-strategies vignette. A drug treatment T affects CD4 count (outcome), mediated partly through Toxicity and Adherence. Hidden common causes link several variables.

g_hiv = make_graph(
    vertices = [:ViralLoad, :Income, :Exercise, :T, :Toxicity, :Adherence, :CD4],

        (:Income,    :T),       (:Exercise,  :CD4),
        (:T,         :Toxicity),(:T,          :CD4),

Simulate data from the DGP

function sim_hiv(n; seed=42)
    Random.seed!(seed)
    # Latent hidden common causes
    U_EI   = randn(n)   # Exercise ↔ Income
    U_ET   = randn(n)   # Exercise ↔ T
    U_ITox = randn(n)   # Income ↔ Toxicity
    U_VA   = randn(n)   # ViralLoad ↔ Adherence
    U_VCD4 = randn(n)   # ViralLoad ↔ CD4

    ViralLoad = randn(n)
    Exercise  = randn(n) .+ 0.5 .* U_EI .+ 0.5 .* U_ET
    Income    = randn(n) .+ 0.4 .* ViralLoad .+ 0.4 .* U_EI .+ 0.4 .* U_ITox
    T         = Float64.(rand(n) .< logistic.(0.5 .* ViralLoad .+ 0.3 .* Income .+ 0.4 .* U_ET))
    Toxicity  = randn(n) .+ 0.6 .* T .+ 0.3 .* U_ITox
    Adherence = randn(n) .+ 0.5 .* Toxicity .+ 0.3 .* U_VA
    CD4       = randn(n) .+ 0.4 .* T .+ 0.3 .* Adherence .+
                            0.2 .* Exercise .+ 0.3 .* ViralLoad .+
                            0.3 .* U_VCD4 .+ 0.2 .* U_VA

    # True ACE(T=1 vs T=0):
    # Direct: 0.4
    # Indirect T→Tox→Adh→CD4: 0.6 × 0.5 × 0.3 = 0.09
    # Total ≈ 0.49

    DataFrame(ViralLoad=ViralLoad, Income=Income, Exercise=Exercise,
              T=T, Toxicity=Toxicity, Adherence=Adherence, CD4=CD4)
end

df_hiv = sim_hiv(2_000)
println("True ACE ≈ 0.49  (0.4 direct + 0.09 through Adherence)")
first(df_hiv, 3)

Estimation

estimate_causal() detects nested-fixable and routes to ANIPW.

res_hiv = estimate_causal(
    a         = [1, 0],
    data      = df_hiv,
    graph     = g_hiv,
    treatment = :T,
    outcome   = :CD4,
)

println("True ACE ≈ 0.49")
@printf("ANIPW: ACE = %.3f  95%% CI (%.3f, %.3f)\n",

Nested rebalancing weights

The ANIPW estimator builds nested rebalancing weights through the intrinsic kernel of each modified district. After reweighting, propensity and outcome regression are estimated by weighted GLM.

rw = res_hiv[:rw]
@printf("Rebalancing weights — min: %.3f  max: %.3f  mean: %.3f\n",
        minimum(rw), maximum(rw), mean(rw))

Part 2: Missing Data with FlexMissing.jl

When covariates are missing at random (MAR), FlexMissing.jl identifies and estimates the missing-data propensity scores, producing per-row IPW weights for estimate_causal().

Workflow

using FlexMissing

# 1. Define the missingness DAG (mDAG)
mdag = FlexMissing.make_graph(
    obs_variables      = ["T", "CD4"],
    missing_variables  = ["ViralLoad"],
    missing_indicators = ["R_VL"],
    di_edges = [("ViralLoad","T"), ("ViralLoad","CD4"), ("ViralLoad","R_VL"),
                ("T","CD4")],
)

# 2. Identify and estimate missing-data propensities
ID    = FlexMissing.ID_algorithm(mdag)
props = FlexMissing.propensity(mdag, data_with_missing, ID; law=:target)

# 3. Build IPW weights on complete cases
obs = .!ismissing.(data_with_missing.ViralLoad)
wts = 1.0 ./ coalesce.(props["R_VL"].pred[obs], 1.0)

# 4. Estimate causal effect using IPW-weighted complete cases
result = estimate_causal(
    a=[1,0], data=dropmissing(data_with_missing),
    graph=g_hiv, treatment=:T, outcome=:CD4,
    sample_weights=wts,
)

G2 graph (FlexMissing.jl)

The G2 example from FlexMissing.jl has six variables with complex dependent missingness patterns. The full runnable code is in FlexMissing.jl/examples/01_identification.jl.

Summary

Strategy Condition Estimator Returns
a-fixable desc(A)∩dist(A) = {A} Backdoor TMLE :TMLE, :Onestep, :Gcomp, :IPW
p-fixable dist(A)∩ch(A) = {} NPS-TMLE :TMLE, :Onestep

All three strategies are accessible through estimate_causal() — routing is automatic based on the graph structure.
