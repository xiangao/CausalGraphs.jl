Estimation: Backdoor and Front-Door

This vignette covers estimation for the two most common identification strategies: a-fixable (backdoor) and p-fixable (front-door / NPS). It uses simulated examples where the true effect is known.

Both examples follow the same workflow:

  1. write down the ADMG that encodes the causal assumptions;
  2. call identify() to check whether the target effect is identified;
  3. call estimate_causal() only after the graph justifies estimation.

The estimand in this vignette is the average causal effect E[Y(1) - Y(0)]. The graph determines whether this estimand can be estimated by covariate adjustment, by a front-door/NPS functional, or not at all.

1. Backdoor Adjustment (a-fixable)

Backdoor identification applies when all noncausal paths from treatment A to outcome Y are blocked by observed pre-treatment variables. In the graph below, X affects both treatment and outcome. If we compare treated and untreated units without adjusting for X, the comparison mixes the effect of A with baseline differences in X.

The adjustment formula is:

E[Y(a)] = sum_x E[Y | A=a, X=x] P(X=x)

For continuous X, the summation is an integral. In the package, the a-fixable check identifies the Markov pillow of the treatment as the adjustment set and routes to backdoor estimators.

Graph

X → A → Y
X → Y
g_bd = make_graph(
    vertices = [:X, :A, :Y],
    di_edges  = [(:X, :A), (:X, :Y), (:A, :Y)],
)
println("strategy: ", identify(g_bd, :A, :Y).strategy)
strategy: a_fixable

Data — true ACE = 2.0

function sim_backdoor(n; seed=1)
    Random.seed!(seed)
    X = randn(n)
    A = Float64.(rand(n) .< logistic.(0.2 .+ 0.8 .* X))
    Y = 1 .+ 2 .* A .+ X .+ randn(n)
    DataFrame(X=X, A=A, Y=Y)
end

Estimation

estimate_causal() returns several estimators for a-fixable graphs:

  • G-computation models the outcome regression E[Y | A, X] and averages predicted counterfactual outcomes.
  • IPW models the propensity score P(A | X) and reweights observations to mimic randomized treatment.
  • One-step/AIPW combines outcome and propensity nuisance models.
  • TMLE updates the outcome regression using the propensity score so that the final estimate solves the efficient influence-function equation.

They estimate the same identified target under the graph, but they use different nuisance-modeling strategies.

res_bd = estimate_causal(a=[1,0], data=df_bd, graph=g_bd,
                          treatment=:A, outcome=:Y)

println("True ACE = 2.0")
@printf("TMLE:    ACE = %.3f  95%% CI (%.3f, %.3f)\n",

2. Front-Door / NPS Adjustment (p-fixable)

Front-door identification is useful when treatment and outcome are confounded, but the causal effect flows through observed post-treatment variables. In the pure front-door graph, A <-> Y says treatment and outcome share an unmeasured cause, so ordinary backdoor adjustment fails. The mediator M helps because:

  1. A causes M;
  2. M causes Y;
  3. the relevant confounding around A -> M and M -> Y is controlled by the observed graph structure.

The classical front-door functional is:

E[Y(a)] = sum_m P(M=m | A=a) sum_a' E[Y | M=m, A=a'] P(A=a')

CausalGraphs.jl implements this class through the broader p-fixable/NPS route. A treatment is p-fixable when none of its children are in its bidirected-connected district. Intuitively, treatment may be confounded with the outcome, but the immediate causal children of treatment are not themselves hidden-confounded with treatment.

Graph

A → M → Y
A ↔ Y   (hidden U confounds A and Y)
X → A, X → Y, X → M
g_fd = make_graph(
    vertices = [:X, :A, :M, :Y],
    bi_edges  = [(:A, :Y)],
    di_edges  = [(:X, :A), (:X, :Y), (:X, :M), (:A, :M), (:M, :Y)],
)
println("strategy: ", identify(g_fd, :A, :Y).strategy)

function sim_frontdoor(n; seed=2)
    Random.seed!(seed)
    X = randn(n); U = randn(n)
    A = Float64.(rand(n) .< logistic.(-0.2 .+ 0.6 .* X .+ 0.5 .* U))
    M = 0.4 .+ 1.2 .* A .+ 0.7 .* X .+ randn(n)
    Y = 1.0 .+ 1.5 .* M .+ X .+ U .+ randn(n)
    DataFrame(X=X, A=A, M=M, Y=Y)
end

Estimation

For p-fixable graphs, estimate_causal() routes to front-door/NPS estimators. The returned estimators are TMLE and one-step variants for the identified NPS functional. These estimators use nuisance models for the treatment mechanism, mediator or intermediate-variable mechanisms, and outcome regression implied by the graph.

res_fd = estimate_causal(a=[1,0], data=df_fd, graph=g_fd,
                          treatment=:A, outcome=:Y)

println("True ACE ≈ 1.8  (= 1.2 × 1.5)")

3. Simulation comparison: TMLE vs Onestep vs IPW

function sim_compare(n_reps=200, n=500)
    tmle = Float64[]; aipw = Float64[]; ipw = Float64[]
    for seed in 1:n_reps
        df  = sim_backdoor(n; seed)
        res = estimate_causal(a=[1,0], data=df, graph=g_bd,
                              treatment=:A, outcome=:Y)
        push!(tmle, res[:TMLE].ACE)
        push!(aipw, res[:Onestep].ACE)
        push!(ipw,  res[:IPW].ACE)
    end
    println("n=$n, reps=$n_reps, true ACE=2.0")
    println("          Bias      RMSE")
    for (name, v) in [("TMLE", tmle), ("Onestep", aipw), ("IPW", ipw)]
        bias = mean(v) - 2.0
        rmse = sqrt(mean((v .- 2.0).^2))
        @printf("  %-8s %+.4f   %.4f\n", name, bias, rmse)
    end
end
